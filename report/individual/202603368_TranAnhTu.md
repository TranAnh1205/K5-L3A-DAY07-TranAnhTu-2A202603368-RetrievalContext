## Retrieval và thử nghiệm

Hit@1 và Evidence Hit@3 yêu cầu chunk chứa **trọn đoạn gold** với đúng nguồn/trang; Context Evidence Rate tự động yêu cầu đoạn đó vào context. Mẫu số 15 dev hoặc 5 test chỉ gồm câu có đáp án. Bảng original-query dùng top-3, budget 2.400 ký tự; cột context agent ở phần sau dùng budget 4.000 ký tự và query agent tự viết.

| Cấu hình | Phương pháp / thay đổi | Split | Hit@1 | Evidence Hit@3 | Context Evidence Rate | Thời gian/chi phí retrieval |
| --- | --- | --- | ---: | ---: | ---: | ---: |
| Phương pháp 1 | TF-IDF, top-3 | dev | 8/15 | 12/15 | 12/15 | median 5.8 ms; API $0 |
| Baseline / phương pháp 2 | Dense Qdrant, top-3 | dev | 8/15 | 12/15 | 12/15 | median 21.3 ms; API $0 |
| Phương pháp 3 / cải thiện 1 | Hybrid RRF, 20+20 candidate, top-3 | dev | 9/15 | 12/15 | 12/15 | median 42.3 ms; API $0 |
| Cải thiện 2 | Hybrid + tối đa 1 lần sửa citation ID, không đổi retrieval | dev | 9/15 | 12/15 | 12/15 | agent 42.79 s; API $0.025743 |
| Baseline khóa | Dense Qdrant, top-3 | test | 1/5 | 2/5 | 2/5 | median 16.48 ms; API $0 |
| Cấu hình đã chọn | Hybrid RRF, top-3, không sửa citation | test | 1/5 | 3/5 | 3/5 | median 28.42 ms; API $0 |

**Hai thử nghiệm cải thiện trên dev.** Cải thiện 1 dùng RRF để hợp nhất TF-IDF và dense: Hit@1 tăng 8/15 lên 9/15, Hit@3 giữ 12/15, nhưng final context agent được chấm đủ bằng chứng 13/15 so với dense 12/15. Ở `d09`, dense lấy nhầm 16,2%→10,6% của hộ chỉ có thu nhập nông nghiệp; Hybrid lấy đúng 66%→46% của hộ có nông nghiệp là *một* nguồn thu. Ở `d13`, Hybrid tìm đoạn giải thích 39% đô thị chính thức và khả năng đo khác cao hơn; dense chỉ lấy ghi chú biểu đồ. Cải thiện 2 thử một lượt sửa ID trích dẫn sai; trong lần chạy đó không cứu được lỗi `d11`, final context giảm 11/15 và mean grounded answer giảm 1,67 xuống 1,47/2, nên không chọn.

Quy tắc đã định trong protocol: chọn Evidence Hit@3 dev cao nhất, hòa điểm thì final Context Evidence Rate đã đọc/kiểm, sau đó latency. Ba cấu hình đều 12/15 Hit@3, nên chọn Hybrid thường (13/15 final context, không repair). Cấu hình và hash corpus/benchmark đóng băng trong [`selected_config.json`](../agent_dev/selected_config.json) **trước** lượt test; không dùng test để chỉnh. Chi tiết dev ở [`agent_dev.md`](../agent_dev.md), chi tiết test ở [`agent_test.md`](../agent_test.md).
